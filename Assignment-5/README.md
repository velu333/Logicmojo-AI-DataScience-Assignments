## How to Use / Getting Started

### Clone the Repository
To get a local copy of this repository, run:

```bash
git clone https://github.com/velu333/Logicmojo-AI-DataScience-Assignments.git
cd Logicmojo-AI-DataScience-Assignments/Assignment-5
```

### Access the Notebook
- Open `assignment_05_velayutham_augustheesan_maths.ipynb` in **Google Colab** or **Jupyter Notebook**.
- All code implementations for Problems 7, 12, 13, 14, and 15 are included here.

### Access the Word File
- Open `assignment_05_velayutham_augustheesan_maths.docx` to view the solutions for Problems 1, 2, 3, 4, 5, 6, 8, 9, 10, and 11.
- Requires **Microsoft Word** or compatible software (e.g., LibreOffice, Google Docs).

### Run the Code
- Ensure you have **Python 3** installed.
- Required libraries: `numpy`, `matplotlib`, `scipy`.
- Install missing packages using pip:

```bash
pip install numpy matplotlib scipy
```

### Optional: Open in Google Colab
- Navigate to [Google Colab](https://colab.research.google.com/).
- Upload the notebook or open it directly from GitHub:

`File → Open notebook → GitHub → https://github.com/velu333/Logicmojo-AI-DataScience-Assignments`
